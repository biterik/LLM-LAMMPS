## What's settled (don't re-derive)

- **Bidirectional cluster-mount rule.** Mac is the durable archive;
  cluster mount is the active workspace.
  - Outbound writes (Mac → cluster): cluster-bound files go via the
    mount directly. No Mac-only + deferred rsync.
  - Inbound mirror (cluster → Mac): **curated, not kitchen-sink.**
    Keep-list: `*.in`, `*.slurm`, `*.py`, `*.dat`, `*.yaml`, `*.md`,
    `*.pdf`, `plots_*/`. Noise-list (NEVER mirror): per-iteration
    `.log`, `log.lammps`, `start_time.txt`/`end_time.txt`, slurm
    `.err`/`.out`, AppleDouble (`._*`, `.DS_Store`),
    `__pycache__/`. Structures (`.data`, `.data.zst`, `.dump`):
    ASK first; default no; if approved, pull via `zstd -19`.
  - Helper: `.lmps/templates/mirror-cluster-to-mac-curated.sh`.
- **L25 mechanism.** Mode/label strings used as `if` boolean operands
  in LAMMPS inputs must avoid `[+*/^-]`. Use underscores.
  Pre-flight grep added to `style/lammps.md` §1.10.
- **L24 mechanism.** When extracting a polynomial coefficient of order
  N, fit at least order N+1 and report the higher-order term as the
  verification that ignoring it was valid.
- **Plot annotation.** Fit plots include the equation form (e.g.,
  `σ = a0 + a1·ε + a2·ε² + a3·ε³`) and the extracted coefficient
  values in physical units. (Future plots; Thread 02 plots predate
  this rule and were not re-generated.)
- **EXTRA-COMPUTE is built into cmmg's lammps/250722** — `compute
  born/matrix` available, both analytical (for supported pair styles)
  and `numdiff` (pair-style independent). See
  `.lmps/lammps-capabilities-cmmg-250722.md`.
- **`lmp` on cmmg requires sbatch — even diagnostics.** The MPI-built
  binary calls `MPI_Init()` before processing `-h`. No `lmp_serial`
  in the module. `I_MPI_HYDRA_BOOTSTRAP=fork mpirun -n 1 lmp` is a
  known login-node workaround; sbatch is the rule.
